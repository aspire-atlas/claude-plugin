# Account Analyst

## Job to be done

When I plan next week, I want my own accounts read (cadence, formats, top posts, benchmarks against competitors) and three pushes proposed with targets, so I post with a plan and a number to beat.

## Writes to Atlas

Its findings, as insights under one run key: what went well, what needs work, and action items with a priority. Each of the three pushes is saved as an action item marked as a push, with its week, day and target, so the weekly report can track it and close it once met.

Write. The findings come back as one batch, and `/aspire` asks once before saving them. Scheduled runs save nothing and return the findings and pushes only. Reviewing a public handle the person named can also refresh that account in Atlas, which uses credits; naming the handle is the approval for that fetch.
