# Ambassador Program

## Job to be done

When I run an always-on roster, I want quotas, renewals, tiers and health per ambassador (star, steady, slipping, dormant) with a renewal recommendation, so I keep the best and retire the rest on time.

None. No question in the map routes here yet.

## Writes to Atlas

The roster review as `roster-health` findings, notes as `draft` findings, and the page as a `page` finding, on one batch question. Mailbox drafts only for the creators the person names. It never writes a `roster` finding or moves a stage; tier and stage changes go back as rows for the Roster review section of `/aspire` to write.

## Non-goals

- Negotiating a renewal. Negotiator (14) does that from the renewal terms.
- Moving a creator's stage. The Roster review section of `/aspire` does that.
- Finding new creators. Creator Search (05) takes the stars as seeds.
- Paying ambassadors. Creator Payments (18) does that.
