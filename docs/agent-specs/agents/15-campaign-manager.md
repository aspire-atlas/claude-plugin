# Campaign Manager

## Job to be done

When a campaign is live, I want one place where every creator's stage, deliverables, due dates, disclosure checks and chases stay current, so nothing slips and I never build a status sheet by hand.

## Writes to Atlas

Write. Deliverable statuses, forward stage moves on the roster, the chase, fix and thank-you
drafts, and the tracker page link, saved after one batch confirmation. Matches it is unsure of
and each "your call" item are asked first, and nothing counts until the person answers. Drafts in
the brand's own mailbox are created only for the creators the person names, and send nothing.
The scheduled posting check saves only the statuses a clear match or the date alone settled,
under the standing approval saved at program setup.

## Non-goals

- Setting up the program and its terms. That is the influencer program setup in `/aspire`, and
  this agent stops when the setup records are missing.
- Sending a chase, a fix request or a thank-you. It drafts them, and the person sends them.
- Checking a post against the brief or the brand guidelines: 17 Content Review.
- Adding posted content to the library and tracking its rights: 26 Content Library and Rights.
- Paying for a posted deliverable: 18 Creator Payments.
- Shipping product and tracking delivery: 16 Product Fulfillment.
- Breaking down one post second by second: 31 Post Analysis.
- Waiving a deliverable. Only the person waives, and the agent never recommends it.
