# CAS creative review

## Job to be done

When a wave's cuts are delivered and nothing has been spent yet, I want one row per variant, what
each pair really tests, and the fixes to make with their timestamps, so I put spend only behind
cuts that are ready and that each test something. When a draft cut comes in, I want the editor's
fixes to the second, so the next version comes back right.
