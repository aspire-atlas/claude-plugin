# Dedupe against roster and past outreach

## What it does

Finds what the team has already decided about each creator on the list, so no one is judged blind twice.

## Inputs

- From brand memory: the team's saved call on each creator, saved partners, vetting lessons,
  and earlier vetting and discovery insights for these creators.
- From the launch message: the list, and for a creator ad lane the campaign, whose roster
  findings show expected cost and earlier work with the brand.

## Output

Per creator: the earlier vetting call and the team's feedback on it, the newest state in any
discovery campaign, and any saved note. A saved reject decides the call, and other saved notes
show on the card. A creator listed with both an Instagram and a TikTok handle is one row with two channels.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
