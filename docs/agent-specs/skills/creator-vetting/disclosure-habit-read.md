# Disclosure habit read

## What it does

Compares a creator's disclosed paid posts with the posts that read as paid but carry no disclosure.

## Inputs

- From brand memory: the hard rejects from vetting setup.
- From the launch message: the list of handles and networks.

## Output

Per creator: a Pass, Flag or Fail citing the posts read. A paid post without a partnership
marker or an ad tag is a Flag, and a Fail when the hard rejects list it. The same pass reports
audience signals: a negative comment share over 30 percent, or engagement that looks bought.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
