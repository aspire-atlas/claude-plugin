# Fee calculator with the creator's own numbers

## What it does

Prices each creator's deal from the brand's fee calculator on the creator's own median views, then reads their performance to set how far the deal can go.

## Inputs

- From brand memory: the `fees:rate-card` record (or the Aspire recommended rates), the program's terms and maximums, and the newest vetting or discovery fit score for the creator.
- From the launch message: the program, the mode, and the creators by network and handle.

## Output

Per creator, an open, target, and max with the math in plain words, and four signals (views, engagement, paid track record, audience fit), each strong, typical, weak, or not judged. The signals set the room the agent may agree without the person. A creator with too little view data gets no price, and the move becomes the person's call.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
