# Terms summary for the agreement

## What it does

Publishes a one-page summary of an agreed deal for the agreement in Aspire.

## Inputs

- From brand memory: the agreed terms for the creator, the program's terms for the deal type, and the brand's page theme.
- From the launch message: the person's approval of the deal.

## Output

One private page per agreed creator, with deliverables, dates, usage and whitelisting, exclusivity, disclosure, and compensation, and its link saved on the deal. It holds only this creator's deal: no budget, maximum, other creator, or performance read.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
