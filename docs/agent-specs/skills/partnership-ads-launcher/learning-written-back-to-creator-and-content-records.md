# Learning written back to creator and content records

## What it does

Saves what each test taught, so the next casting and the next cut start from it.

## Inputs

- From brand memory: the creator's and the post's earlier learnings.
- From the launch message: the closed tests and the person's save approval.

## Output

One finding per creator and per post: what ran, the result against the target, and the lesson in one
line ("Problem-first hooks beat product-first for this lane"). Each is labelled as an observation or
an inference. Saved on one batch question.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
