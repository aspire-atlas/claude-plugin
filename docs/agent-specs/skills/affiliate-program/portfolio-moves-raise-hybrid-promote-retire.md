# Portfolio moves: raise, hybrid, promote, retire

## What it does

Recommends one move per creator from their sales against the program median and their own trend.

## Inputs

- From brand memory: the enrollment terms and earlier `affiliate` report findings.
- From the launch message: the period's figures.

## Output

One move per creator with its evidence. Raises, hybrid moves, and promotions are handed to Negotiator (14). Retirements are handed to Promo Codes (20).

## Callable

Never user-callable. Only Affiliate Program runs it.
