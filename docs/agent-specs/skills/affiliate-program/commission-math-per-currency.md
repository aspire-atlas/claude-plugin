# Commission math per currency

## What it does

Works out commission owed per creator for each closed month, in each currency.

## Inputs

- From brand memory: the enrollment terms.
- From the launch message: the imported rows.

## Output

Per creator: orders, revenue, average order value, and commission, per currency, never converted or added across currencies. A platform figure that differs comes back as a question.

## Callable

Never user-callable. Only Affiliate Program runs it.
