# Sales to post timeline

## What it does

Lines daily sales by code up against the creator's posts in Atlas, and shows each post's views and engagement.

## Inputs

- From brand memory: the program's `deliverable` findings that carry a post link.
- From the launch message: the imported rows. Posts are read with `search_posts`, with the Program tracking row's required metrics.

## Output

A timeline per creator, labelled as correlation, with views, likes, comments, and engagement per 1,000 views on every post it lists, or a note saying why one is missing. It never says a post drove a sale.

## Callable

Never user-callable. Only Affiliate Program runs it.
