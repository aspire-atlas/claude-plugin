# Sales to post timeline

## What it does

Lines daily sales by code up against the creator's posts in Atlas.

## Inputs

- From brand memory: the program's `deliverable` findings that carry a post link.
- From the launch message: the imported rows. Posts are read with `search_posts`.

## Output

A timeline per creator, labelled as correlation. It never says a post drove a sale.

## Callable

Never user-callable. Only Affiliate Program runs it.
