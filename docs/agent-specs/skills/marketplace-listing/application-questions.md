# Application questions

## What it does

Writes three to six application questions, each testing one criterion the campaign needs.

## Inputs

- From brand memory: the campaign's saved criteria.
- From brand memory: `red_line` calibrations.
- From the launch message: the campaign to list.

## Output

An ordered list of questions, each with its answer type and the criterion it tests.

## Callable

Never user-callable. Only Marketplace Listing runs it.
