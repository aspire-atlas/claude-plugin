# Paid-readiness verdict with fixes

## What it does

Answers the brand's question about the post in one verdict, with the changes that would make it usable.

## Inputs

- From brand memory: the brand summary, business context, competitors, partners, red lines and campaign briefs.
- From the launch message: the post's link, the recipient lens, whether the person chose to save findings, and any earlier analysis of the same post.

## Output

A lead sentence that answers the question, four or five findings each with a number, three to five takeaways for the brand, and the fixes (the trim, a disclosure ask, rights to clear). With a paid or creative lens, it adds the hook score, the hook pattern and a cut list. When saving was chosen, these become findings under one run key; any value that changed from the earlier analysis is shown old to new.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
