# Chase and fix-request drafts

## What it does

Drafts a polite chase, an exact fix request, or a thank-you for each creator who needs one, ready for the person to send.

## Inputs

- From brand memory: the brand summary, the voice guideline and content operations fact, the outreach channels saved for the program, and each creator's name, contact and manager on the roster row.
- From the launch message: the approval to save the drafts, the creators whose drafts go into the brand's own mailbox, the mailbox connection, and the reader the run is for.

## Output

One draft per creator, template and channel: a chase for a late post, a note for a missing one, a fix request naming each change, or a thank-you once every post due is up. Each has a subject, a body and any bracketed blanks to fill. No draft names a fee, the budget or another creator's terms. Mailbox drafts send nothing.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
