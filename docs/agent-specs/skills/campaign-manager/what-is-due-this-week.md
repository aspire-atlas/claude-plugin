# What is due this week

## What it does

Lays out every post due in the next seven days so the person sees what is coming before it is late.

## Inputs

- From brand memory: the owed list with each row's due date, built from the deal and the product delivery dates, and the cadence timezone for today's date.
- From the launch message: the program slug and any creators to limit the run to.

## Output

A seven-day calendar from today, each day listing the creators and deliverables due, plus one line for rows with no date set. The chat summary repeats it as one line per day that has something due.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
