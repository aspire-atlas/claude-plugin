# Cadence and format mix

## What it does

Reads how often each of the brand's accounts posts and which formats it uses.

## Inputs

- From brand memory: the digest of the brand's calibrations (summary, goals, competitors, red lines, partners).
- From the launch message: the profile, the target mode, every linked handle and network, the reader lens, and whether the run is interactive or scheduled.

## Output

Per account: posts per week over the window, the mix of formats (Reels, video, image, carousel) sized from the last 100 posts, and engagement per post against follower count. It also flags any post that touches a saved red line. Feeds the insights and the pushes.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
