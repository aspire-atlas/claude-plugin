# Three pushes with day, format and target

## What it does

Turns the account's patterns into three content pushes for next Monday to Sunday.

## Inputs

- From brand memory: red lines (including any that block written copy), goals and competitors.
- From the launch message: the profile, the linked handles, and the reader lens.

## Output

Three pushes, strongest pattern first, each with the format and length, the angle, the day from the account's best weekdays, the pattern and evidence post it builds on, and a target from the account's own medians (for example 1.5 times median Reel views). It describes ideas and never writes captions or scripts. In an interactive run each push is proposed as an action item to save. A push that needs creators or a budget is named in one line for the creator brief.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
