# Benchmark against indexed competitors

## What it does

Compares the brand's accounts with the competitors Atlas already holds, on rates rather than raw counts.

## Inputs

- From brand memory: every competitor record with its handle, and the 90-day goal.
- From the launch message: the profile and the target mode (own accounts only).

## Output

Per competitor Atlas holds: engagement per post against follower count, posts per week, format mix and median views on video over the last 90 days, set against the brand's own, with the gaps and quick wins against the goal. A competitor Atlas does not hold is named under data gaps; it never starts a fetch for one.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
