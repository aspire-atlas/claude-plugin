# Campaign and program report

## What it does

Shows how a campaign launch or a whole influencer program is going, against its goals.

## Inputs

- From brand memory: for a launch, the open `campaign:{slug}-pulse` records. For a program, its setup records and every program record (roster, deals, orders, posts owed, content and rights, affiliate sales, ledger, roster review), and the performance of the program's posts.
- From the launch message: the campaign slug or program slug, the approvals to save the snapshot and to post to the saved routing, and the reader the run is for.

## Output

For a launch, a pulse section in the daily report: day of the window, creators live, mentions against the day before, and how it is landing with a quoted post. For a program, one dashboard: headline numbers against the goals with pacing, the funnel by stage, deliverables, content and rights, performance against each creator's own baseline, spend and sales in the team view only, roster health, and an attention list naming the agent for each item. With approval, a snapshot of the headline numbers is saved.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
