# Per-creator report

## What it does

Shows how each creator in the program performed against their own baseline.

## Inputs

- From brand memory: the program's roster and deliverable findings, and each posting creator's own posts in the 90 days before the program.
- From the launch message: the program slug and the reader the run is for.

## Output

No standalone per-creator report exists today. The program dashboard gives each creator a row: program posts, engagement against their own baseline (judged with two or more program posts and five or more of their own), and their top post. The weekly report's growth section names the creators to back next.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
