# Goal to deliverables

## What it does

Turns the campaign's goal into a deliverable list sized to the campaign window, grouped into before, during, and after.

## Inputs

- From brand memory: the campaign description and window from the campaign record, the campaign's criteria, `brand:summary`, red lines and guidelines, and the saved market signal and weekly readout findings on what the brand won on.
- From the launch message: the campaign name, the first post date, the campaign end date, and the creator roles wanted.

## Output

A list of deliverables, each with its phase, format and length, angle, must include, and avoid: at least one launch-day post per first-pick creator, teasers only when the brand's history shows them working, and sustain posts through the window. A red line on AI-written content makes it strategy only, with no captions or scripts. The agent is not built yet; the creator brief's campaign mode does this until it is.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
