# Tagging: product, theme, format, hook, people, safety

## What it does

Tags each asset so anyone can filter the library in plain words.

## Inputs

- From brand memory: the catalog, the theme list, red lines, and the brand safety categories.
- From the launch message: nothing.

## Output

Per asset: products with the field or frame time that matched, themes, format, hook pattern, ad
readiness score with its six parts (frames for the top 12 new or changed videos, fields for the
rest), people on screen by count and role, never named from their face, and a brand safety call. A
tag with no evidence stays empty.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
