# Collection from programs, mentions and hashtags

## What it does

Gathers every creator post about the brand that Atlas already holds into one catalog.

## Inputs

- From brand memory: the programs in scope and their rosters, the brand's handles, tracked
  hashtags, and competitors.
- From the launch message: one program or the whole brand, and the window.

## Output

One asset per post, with every source that found it (program creator, tag or mention, hashtag).
Competitors' posts are left out. An empty run names the sources it searched and says indexing may
still be running.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
