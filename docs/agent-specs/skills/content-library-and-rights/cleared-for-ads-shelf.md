# Cleared for ads shelf

## What it does

Shows only the assets the brand may run as ads today.

## Inputs

- From brand memory: the joined rights.
- From the launch message: any filter in the person's words ("unboxing videos of the trail shoe").

## Output

The assets with a current paid usage or whitelisting grant, from a grant or the deal, sorted by ad
readiness, each with its channels and end date. Organic repost alone shows apart as "cleared for
organic". A grant not in writing carries "Get this in writing".

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
