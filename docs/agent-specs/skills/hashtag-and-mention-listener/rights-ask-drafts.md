# Rights ask drafts

## What it does

Drafts a short ask to repost each chosen candidate organically, with credit and duration.

## Inputs

- From brand memory: existing rights records for the post, so nothing already granted is asked for again.
- From the launch message: the candidates the person chose.

## Output

A draft per creator. Each send is confirmed one by one. It never asks for paid usage.

## Callable

Never user-callable. Only Hashtag and Mention Listener runs it.
