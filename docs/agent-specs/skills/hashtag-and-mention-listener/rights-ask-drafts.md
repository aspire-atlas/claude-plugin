# Rights ask drafts

## What it does

Drafts a short ask to repost each chosen candidate organically, with credit and duration.

## Inputs

- From brand memory: the post's `rights` findings, so nothing already granted is asked for again.
- From the launch message: the candidates the person chose.

## Output

A draft per creator. Each send is confirmed one by one. It never asks for paid usage. A creator's yes is handed to Content Library and Rights (26), which records it as a `rights` finding with its proof.

## Callable

Never user-callable. Only Hashtag and Mention Listener runs it.
