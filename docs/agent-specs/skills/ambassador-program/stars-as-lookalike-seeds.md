# Stars as lookalike seeds

## What it does

Offers the stars as seeds for finding similar creators.

## Inputs

- From the launch message: the segments from Health segments with evidence.
- From the launch message: whether the person wants seeds handed on.

## Output

A `seeds` block for Creator Search (05) with each star's handle and why they lead the roster.

## Callable

Never user-callable. Only Ambassador Program runs it.
