# Re-engagement and thank-you drafts

## What it does

Drafts re-engagement notes for slipping and dormant ambassadors and thank-you notes with a rebook invite for stars.

## Inputs

- From brand memory: `program:{slug}-outreach` for templates and voice.
- From the launch message: the segments, and the creators the person names for mailbox drafts.

## Output

A note draft per ambassador. Mailbox drafts only for the named creators; nothing is sent.

## Callable

Never user-callable. Only Ambassador Program runs it.
