# Health segments with evidence

## What it does

Puts each ambassador in one segment (star, steady, slipping, dormant, retire, or not enough data) with the evidence behind it.

## Inputs

- From brand memory: the quota counts, `ledger` lines or the agreed deal for cost, `affiliate` findings, and `red_line` calibrations.
- From the launch message: the review window.

## Output

A segment per ambassador citing quota, posts against their own and the roster's, cost per engagement, sales, sentiment, reply speed, and any red line. A signal with no data is "not judged".

## Callable

Never user-callable. Only Ambassador Program runs it.
