# GMV and conversion report

## What it does

Reports GMV, orders, and conversion by creator, video, and LIVE for the period, from Partner Center.

## Inputs

- From brand memory: earlier `shop-campaign` report findings, for the trend.
- From the launch message: the period.

## Output

Figures per creator with source and currency on every total, never converted, and one next move per creator: keep, raise commission (a question for the person), or drop.

## Callable

Never user-callable. Only TikTok Shop Campaigns runs it.
