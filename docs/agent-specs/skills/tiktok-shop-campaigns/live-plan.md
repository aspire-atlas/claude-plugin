# LIVE plan

## What it does

Proposes LIVE sessions with hosts chosen from creators who already sell on LIVE, with products, dates, and a running order.

## Inputs

- From brand memory: `program:{slug}-catalog` or the Shopify catalog.
- From the launch message: the period and any launch date.

## Output

A plan row per session with the host, products, date, and the LIVE GMV that picked the host.

## Callable

Never user-callable. Only TikTok Shop Campaigns runs it.
