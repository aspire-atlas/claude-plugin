# Goals and economics capture

## What it does

Records the brand's 90-day goal, what a good week looks like in numbers, and offers to set the creator rate card.

## Inputs

- From brand memory: the business context, the weekly target, and the rate card or a declined rate card, if already saved.
- From the launch message: the profile and the person's answers to the goal and weekly target questions.

## Output

The 90-day goal as business context, and the weekly target with what it measures and what it does not cover; a person who cannot set targets has them saved as a known gap instead. At the end it hands off one offer to set the creator rate card, which `/aspire`'s fee calculator saves. Economics read from a connected store catalog are not built yet.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
