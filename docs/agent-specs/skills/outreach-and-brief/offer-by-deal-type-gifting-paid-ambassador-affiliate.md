# Offer by deal type (gifting, paid, ambassador, affiliate)

## What it does

States the program's offer for the creator's deal type at the level the saved terms allow.

## Inputs

- From brand memory: the program's terms for each deal type (deliverables, posting window, disclosure, commission and code discount, monthly fee, first-touch setting), the product catalog, and the `fees:rate-card` record.
- From the launch message: the program and each creator's deal type from the roster.

## Output

One offer passage per draft. Gifting names the product, never its value. Paid and ambassador invite a talk about the fee, unless the program opens with a fee from the fee calculator. Affiliate states the commission and the code discount. The maximum, the budget, a product value limit, and other creators' terms never appear. Anything the records do not hold is a bracketed blank.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
