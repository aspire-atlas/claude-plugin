# One pipeline page

## What it does

Publishes one outreach page per program that shows the whole pipeline and what needs doing next.

## Inputs

- From brand memory: the roster, drafts, and replies for the program, the link to the existing outreach page, and the brand's page theme.
- From the launch message: the program and the reader.

## Output

The page link. The page holds a headline with the reply rate, creators by stage as one bar chart, replies to record, drafts waiting with copy buttons, follow-ups due, reply rate by channel and tier, creators with no reply, and creator cards. It never shows the budget, the maximum, an email address, or a reply's full text.

## Callable

Never user-callable. Only the agent that owns it, or every agent for a shared or universal skill,
runs it.
