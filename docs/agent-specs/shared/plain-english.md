# Plain English writing

## What it does

Keeps every sentence an agent writes short and plain: no em dashes, everyday words, and headlines that read as one phrase.

## Inputs

- From the launch message: the reader, so the wording fits them.

## Output

Text that passes the plain language check (R11 in the reader standard).

## Callable

Never user-callable. Every agent links it, and it is never counted in an agent's own skills.

## Lives in today

`plugins/aspire/skills/aspire/references/reader-standard.md` (R11)
