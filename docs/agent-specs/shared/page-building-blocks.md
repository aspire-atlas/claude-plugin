# Page building blocks

## What it does

Gives every page the same tested parts (creator cards, evidence rows, charts, decision blocks) so pages reach the same quality without looking the same.

## Inputs

- From the launch message: the kind of page and the reader.

## Output

The parts the page is built from.

## Callable

Never user-callable. Every agent links it, and it is never counted in an agent's own skills.
