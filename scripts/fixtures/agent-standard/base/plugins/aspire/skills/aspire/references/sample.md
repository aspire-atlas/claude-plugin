# Sample flow

Follows **Artifact standard**. Run page-standard's **Build loop**, and say how fresh the data is
per its **Data freshness** rule.

Every image on the page is a data URI. Never put a data URI in a reply or a widget.

```html
<section data-question="O1">
  <h2>What landed last week</h2>
  <p>Atlas compared 24 posts. "Our API launch" is the creator's own caption.</p>
  <blockquote>The schema of a good unboxing, in her words</blockquote>
</section>
```
